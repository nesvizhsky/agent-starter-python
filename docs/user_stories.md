# User Stories

> Stage 3: Operationalize success as UX. Draft for user review.

## Topic management

- As a user, I want to add a topic (e.g. "Ukraine war") with a name, description, and list of
  sources to watch, so the bot knows what to cover and where to look.
- As a user, I want to set how often I get updates per topic (daily, twice a day, weekly),
  so it matches how fast that topic moves.
- As a user, I want to pause or remove a topic, so I stop getting updates when I'm not interested.
- As a user, I want to ask for an extra check on a topic outside the regular schedule,
  so I can get a fresh look when something big happens.

## Receiving digests

- As a user, I want each digest to cover only genuinely new developments since my last update
  on that topic, so I'm not re-reading things I already know.
- As a user, I want to see the same story told from multiple source perspectives in one digest,
  so I can compare narratives without hunting across sites.
- As a user, I want the digest delivered in a rotating persona (Socrates, a medieval monk,
  a Terminator, Shakespeare…), so it's entertaining to read and I remember it's a framing,
  not a verdict.
- As a user, I want to pin a favourite persona for a topic, so if I find one works especially
  well I can keep it.
- As a user, I want to know when there's genuinely nothing new, rather than the bot padding
  an update with old material.

## Propaganda analysis

- As a user interested in contested topics, I want the bot to flag rhetorical manipulation
  signals in the sources it read (one-sided framing, loaded vocabulary, appeal to "common sense",
  dehumanizing language, false equivalences), so I can read sources more critically.
- As a user, I want the propaganda analysis delivered in the same fun-persona style as the digest,
  so it feels like insight, not a lecture.
- As a user, I want propaganda analysis applied to *all* sources by the same criteria,
  so the bot doesn't have its own ideological lean.

## Deep dives

- As a user, I want to ask the bot "tell me more about X" after a digest, so I can go deeper
  on the part that interested me.
- As a user, I want a weekly synthesis on a topic — how the narratives shifted, what patterns
  emerged, what seems confirmed vs contested — so I build a longer-term picture.

## Source control and feedback

- As a user, I want to tell the bot "trust this source more" or "exclude this source",
  so the digest quality improves over time for my taste.
- As a user, I want to add a custom source URL to a topic, so I can track outlets the bot
  didn't know about.
- As a user, I want to give quick feedback on a digest (too long, too shallow, good one),
  so the bot learns my preferences without requiring me to write paragraphs.

## Multi-user

- As one of many users, I want my topics, sources, and preferences to be entirely separate
  from other users', so my feed is mine and nobody else's.
